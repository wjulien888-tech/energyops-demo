# 负荷预测结果接入（2026-11-05）

## 已实现

- 页面默认 DormPatch-96，支持 DormLinear-96 / 演示负荷切换。
- 使用冻结的两套模型输出，各14个归档测试日，每日96个15分钟功率。没有改写日期伪装实时预测。
- 展示96点表格和预测/参考曲线；参考空值留空，MAE/RMSE/R²仅用存在参考标签的点计算。页面指标是所选日，非全部测试日总体指标。
- 每四个预测功率取均值得到24个小时功率供现有调度内核使用，`sum(P15)*0.25 == sum(P60)`。不得直接把96点传给1小时内核。
- 模型、版本、起点、日期或96点序列改变均使旧预测输出失效；日期变化使参数输出一起失效。未重新输出不得生成新计划。
- 输出快照和计划输入保留96点原值、掩码、模型版本、发报时间和输入SHA256；导出96步JSON，报告区分训练负荷与合成PV。
- 无实时Python推理服务、无新增AI调用或设备控制。模型权重和原始SQL不在网页包中。

## 数据口径

负荷参考由SE4-ZALGL1原小时累计读数差分，经每小时功率保持四步构造；不是独立15分钟实测。原标签缺失的四点都保留null，不进入参考误差。训练历史填补和参考标签评分是独立口径。96点预测数值完整，不因参考缺失而补零。电表单位kWh及倍率已计入的解释仍待业务确认。

发报起点为归档日期00:00，Asia/Shanghai，不能使用旧Demo“前日18:00”冒充模型发报时间。光伏、电价、碳因子与负荷处于组合演示场景，不表示同地点同步实测。旧调度设备假设未因负荷接入而自动改为研究配置，研究单柜参数单独保存在研究工作区配置文件。

当前主页面为中文/英文简洁展示，数据来源、架构和重采样口径放在“模型详情”中。导出的归档结果可用于后续真正API的契约样例，但当前不存在 `/api/forecast` 后端。
