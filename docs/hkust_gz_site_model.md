# 港科广真实场地建模说明

当前 Blender 场景结合用户提供的港科广地图截图细化到西科研楼、东科研楼、学术研究中心、图书馆、行政办公楼、C2 学生活动中心、红鸟广场、体育馆、幼儿园、宿舍 1A/1B/2B/6A/6B/6C 和可持续大气环境中央实验室。

当前几何坐标是根据公开校园规划和地图截图建立的可渲染近似，不是测绘/CAD 竣工图。精确坐标、高程、屋顶面积和配电设备位置仍需用校园总平面图、GIS、CAD 或现场资料校准。

```bash
blender --background --python video/create_energyops_scene.py
bash video/render_hpc_cpu.sh
```
